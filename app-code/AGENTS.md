# 渲心 - 心情画应用

> 一句话，渲出一颗心。

## 项目概览

「渲心」是一款丹青风心情画应用。用户输入一句话描述心情/今天干的事，AI 生成一张 2048×2048 的纯抽象丹青风格画作，支持心情墙多视图回顾、情绪色盘和基础社区广场。

## 技术架构

- **前端**：React 19 + TypeScript + Tailwind CSS + shadcn/ui + ECharts
- **后端**：NestJS 10 + Drizzle ORM + PostgreSQL
- **AI 能力**：ai-text-to-image 插件（文生图）
- **用户体系**：基于平台内置用户系统（妙搭账号）
- **文件存储**：平台云存储（dataloom）

### 字体

- **标题字体**：衬线字体 `'Noto Serif SC', 'Source Han Serif SC', Georgia, serif` — 用于品牌名、Slogan、大标题
- **正文字体**：沿用系统无衬线字体 — 用于正文、按钮、表单

### 视觉元素

- 宣纸纹理背景：暖米底色 + 极淡水墨晕染光斑
- 玻璃质感卡片：半透明白底 + 模糊背景 + 细边框 + 柔和阴影
- 装裱画框：细线边框 + 内留白 padding
- 朱砂印章：圆角方形 + 朱砂红 + 印章"心"字点题
- 整体清透、不脏不糊，留白充足

### 间距与圆角

- 卡片圆角：`12px`（装裱感，不过圆）
- 按钮圆角：`8px`
- 内边距：卡片 `24px`，画框留白 `16px`
- 区块间距：`24px` / `32px`

## 情绪分类与配色

生成前先判断心情的情绪类别，不同类别用不同主导色与构图动势：

| 情绪 | 主导色 | 辅助色 | 焦点色 | 构图动势 |
|------|--------|--------|--------|----------|
| 喜悦雀跃 joy | 朱砂红 | 鎏金 | 亮金 | 放射绽放 |
| 悲伤孤独 sad | 青墨冷沉 | 石青灰 | 留白 | 低沉下坠 |
| 思念牵挂 longing | 青蓝雾感 | 淡紫 | 暖金微光 | 流动上升 |
| 紧张兴奋 anxious | 朱砂+金 | 深墨 | 亮红 | 快速交错 |
| 疲惫压力 tired | 深墨+石绿 | 灰蓝 | 暗沉 | 下坠厚重 |
| 平静放松 calm | 暖金淡赭 | 石绿 | 柔光 | 舒展留白 |
| 满足高效 productive | 石青稳亮 | 鎏金 | 清晰块面 | 稳静秩序 |
| 温暖治愈 warm | 石绿+暖金 | 朱砂淡 | 圆润柔光 | 包裹流动 |

情绪分类通过前端关键词映射实现，同时在 prompt 中注入风格描述。

## 页面结构

1. **首页** (`/`) - 心情生图核心功能
2. **心情墙** (`/wall`) - 周/月/年三视图切换
3. **情绪色盘** (`/palette`) - 年度情绪色彩曲线
4. **心情广场** (`/plaza`) - 瀑布流 + 发布 + 互动
5. **我的** (`/me`) - 账号与作品管理

底部导航（移动端）/ 侧边导航（桌面端）。

## 数据模型

### mood_works（心情作品表）
- id, user_id, mood_text, image_url, emotion_category, dominant_colors(JSON), created_at
- 按 user_id 索引

### plaza_posts（广场发布表）
- id, work_id, user_id, caption, supplement_text, like_count, comment_count, created_at

### plaza_likes（广场点赞表）
- id, post_id, user_id, created_at
- UNIQUE(post_id, user_id)

### plaza_comments（广场评论表）
- id, post_id, user_id, content, created_at

## 核心交互流程

### 生图流程
1. 用户输入心情文字
2. 前端判断情绪分类 → 组装丹青风格 prompt
3. 调用 ai-text-to-image 插件生成 2048×2048 图片
4. 展示大图 + 下载 + "再来一张"
5. 登录用户自动保存作品到服务端；未登录提示登录

### 心情墙
- 周视图：横向滚动瀑布流，每天 1 张缩略图 + 心情短语
- 月视图：7×5 日历网格，格子内缩略图/主色
- 年视图：GitHub 贡献图风格，365 格情绪色马赛克
- 点击任意格 → 弹窗展示大图 + 心情文案
